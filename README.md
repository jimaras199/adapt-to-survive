# Adapt to Survive

A modular 2D survival simulation developed in C++20, where an
autonomous agent learns survival behavior through reinforcement learning.

## Project Goals

- Build a deterministic 2D survival environment.
- Implement hunger, thirst, health, movement, and interactions.
- Train an autonomous agent using Proximal Policy Optimization (PPO).
- Use a recurrent neural network (GRU) for learned memory.
- Allow the agent to discover survival strategies independently.
- Visualize the simulation using SFML.
- Maintain a modular, testable C++ architecture.

## Planned Technologies

- C++20
- CMake
- EnTT
- LibTorch
- SFML 3
- GoogleTest
